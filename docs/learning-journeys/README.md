# Partner learning journeys

Learning journeys connect multiple certifications and applied-learning requirements into a larger program or badge. They are kept separate from the certification catalog because completing one journey may involve several exams, gated courses, assessments, account-linking steps, and organization-specific eligibility.

These pages use only publicly visible program information. They link to the library's existing certification guides and explain where authorized partner access is required; they do not reproduce gated course material or assessment questions.

## Available journeys

### [Frontier Transformation Engineer](frontier-transformation-engineer.md)

A Microsoft-sponsored LevelUp journey for eligible partner technical professionals. Its certification milestone requires **GH-300**, **AI-103**, and **AB-100**, followed by project-readiness assessments and the required Hypervelocity Engineering Framework assessment.

**Public baseline:** 11 courses, approximately 86 hours, and three milestones as displayed September 1, 2026. LevelUp enrollment and learning content require an eligible Microsoft partner work account.

## Counting rule

A journey page does not add another certification guide or inflate the published-guide total. Each required certification remains one guide; the journey is a navigational and planning layer over those guides.
