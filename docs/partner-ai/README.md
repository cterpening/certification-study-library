# Partner AI certification references

These pages cover certification programs that matter to partner audiences and
record when public evidence supports a future blueprint-mapped guide. They
separate three things:

- facts verified from public first-party pages;
- an independent learning map built from public product documentation; and
- partner-only material that an authorized downstream mirror may add.

This is the honest middle ground between ignoring a useful partner credential
and inventing objectives from a private course. Recheck the dated contract table
before relying on a page, because these programs and products can change quickly.
