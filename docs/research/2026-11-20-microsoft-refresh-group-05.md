**Product documentation.** For incremental Dataverse synchronization of a finance and operations data entity, identify every participating table that needs row version change tracking. SQL Server updates the database-wide counter on inserts and updates. Treat the rowversion as a change marker, distinct from a timestamp or business sequence.
