## Material changes

- **Runtime boundaries:** correct the stale answer describing the GitHub Copilot
  harness as wholly preview. Identify individual feature status and prohibit
  inferred support across harnesses. Scope the current Fabric IQ Data MCP tool
  to its GitHub harness and distinguish User from Maker credentials.
- **Foundry integration:** explain the standard-harness preview connector's
  Activity-protocol prerequisite, its REST/SDK enablement and the portal display
  limitation. Separate this failure from an older Foundry agent's version error.
  Distinguish managed prompt catalogs from BYO chat-completions/model restrictions.
- **Identity and interaction:** separate secure web-channel propagation from
  authentication publishing, user identity and backend authorization. Explain
  token-variable changes, background execution with blocked maker credentials,
  card host versions and repeated submission. HTTP error continuation needs an
  explicit failure branch.
- **Approval and computer use:** default AI rejection can bypass a later human
  stage. Add path arithmetic and a promotion lab for advanced approvals that
  require recreation after import/sharing. Computer-use supervision can miss a
  desired pause; enforce required approvals separately and respect intended-use
  limits.
- **Knowledge:** document the custom trigger, rewritten query, result contract
  and shared 15-snippet cap. Add server-side authorization/ranking arithmetic.
  Keep formal Search connection creation separate from recovery-specific Entra
  advice; do not recommend hand-built endpoint/key configuration or destructive
  recovery as a lab. Citations and service authentication do not establish
  per-document access control.
- **Evaluation:** replace the old blanket statement that evaluation excludes
  safety. Current methods include Content Safety and Custom grading, with bounded
  coverage. Add refusal-specific expectations, test-profile data exposure,
  explicit denominator metrics, independent latency gates and 89-day export
  planning. An original confusion matrix exposes missed violations hidden by
  overall accuracy.
- **Operations:** distinguish agent-level telemetry from preview environment
  export, including tables, up-to-24-hour initial delay, unsupported configurations,
  missing topic/duration fields and nontransactional delivery. Add a peak-pilot
  extrapolation worksheet; purchased credits do not establish throughput.
