## AB-100

[Study guide](../../guides/AB-100-agentic-ai-business-solutions-architect.md) · [Official objectives](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/ab-100)

Confirm eligibility with Microsoft if relying on either.

[Credential](https://learn.microsoft.com/en-us/credentials/certifications/agentic-ai-business-solutions-architect/) · [Exam route](https://learn.microsoft.com/en-us/credentials/certifications/exams/ab-100/)

**Product documentation.** When two agents only repeat a single model call, benchmark the direct call first. Split responsibility when one stage depends on another result or requires a distinct tool or decision owner. Measure the extra handoffs and latency against the business outcome.

[AI Agent Orchestration Patterns - Azure Architecture Center | Microsoft Learn](https://learn.microsoft.com/en-us/azure/architecture/ai-ml/guide/ai-agent-design-patterns)

The November Copilot Studio guidance index lists agent model assessment as preview. Agent-specific tenant rollout and gated tool execution were not tested.

Public lessons can be read independently. Practice with Dynamics 365 or Power Platform requires appropriate access. The module is a design sequence, not complete AB-100 coverage. [Publisher resource](https://learn.microsoft.com/en-us/training/modules/design-ai-agents-business-solutions/)
