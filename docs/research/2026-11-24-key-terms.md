# Key terms and phrases across the certification guides

On November 24, 2026, the library expanded its glossaries to **10,439 entries across 227 guides and 26 vendors**. The median guide has **47 entries**, with a range of **35–70**. The **Exam essentials** panel links to each guide’s glossary, immediately before **Places to learn**.

The pass includes active, beta, archived and pre-publication guides listed in the exam catalog. Inventory entries without a study guide have no glossary. For the Fortinet MSSP pre-publication reference, the terms describe managed-service practice while the exam objectives are unpublished. Elective guides identify when a term belongs to a particular path. [Fortinet MSSP certification page](https://training.fortinet.com/local/staticpage/view.php?page=nse_industry_mssp_security)

## Expanded reference sections

The expansion added 8,572 entries to the original 1,867. Each glossary groups related terms by subject and links every entry to the lesson, example or calculation that explains it. The counts represent entries within individual guides. A shared term can have a different example in each certification. [Expanded packet and hash record](2026-11-24-key-terms-depth-evidence.json)

The A+ Core 1 guide distinguishes the frame rate of a video source from a display’s refresh rate. The Cisco networking guide uses a floating static route to explain how a backup route takes over. The AWS architecture guide divides $2,400 by 800,000 successful transactions to show how to compare unit costs across workloads. [CompTIA A+ Core 1](../../guides/220-1201-comptia-a-plus-core-1.md#key-terms-and-phrases) · [Cisco CCNA](../../guides/200-301-cisco-certified-network-associate.md#key-terms-and-phrases) · [AWS Solutions Architect Professional](../../guides/SAP-C02-aws-certified-solutions-architect-professional.md#key-terms-and-phrases)

The expansion used the same 25 small review packets. Separate AI reviewers checked the changes against complete guides, retained objectives and teaching references. Corrections included distinguishing an admission webhook from event delivery, DynamoDB item expiry from prompt-cache expiry, and a Unity Catalog schema from the structure of a data record. [Kubernetes admission webhooks](https://kubernetes.io/docs/reference/access-authn-authz/extensible-admission-controllers/) · [DynamoDB time to live](https://docs.aws.amazon.com/amazondynamodb/latest/developerguide/TTL.html) · [Amazon Bedrock prompt caching](https://docs.aws.amazon.com/bedrock/latest/userguide/prompt-caching.html) · [Unity Catalog securable objects](https://docs.databricks.com/aws/en/data-governance/unity-catalog/access-control/privileges-reference)

## Initial glossary pass

Each guide was read against its existing topics, examples and objective evidence. Closely related terms share a scenario when it makes the distinction easier to learn. The machine-learning guide uses one set of predictions to calculate precision and recall. The Azure architecture guide uses one outage to show the difference between the recovery deadline and the age of recovered data. The Excel guide shows which part of a formula changes when it moves down a row. [AWS Machine Learning Engineer](../../guides/MLA-C01-aws-certified-machine-learning-engineer-associate.md#key-terms-and-phrases) · [Azure Solutions Architect](../../guides/AZ-305-designing-microsoft-azure-infrastructure-solutions.md#key-terms-and-phrases) · [Excel Associate](../../guides/MO-210-microsoft-excel-microsoft-365-apps.md#key-terms-and-phrases)

The research and review used 25 packets of five to twelve guides. Research workers supplied proposed terms and teaching passages. The coordinator reconciled entries and checked scope, wording, worked examples and placement. Separate fresh-context AI reviewers checked the glossary changes against the complete guide files, objective snapshots and section evidence. The retained record binds each packet to the guide and objective texts. [Packet and hash record](2026-11-24-key-terms-evidence.json)

## Technical corrections from review

- A CloudWatch alarm's period sets the length of a data point. The number of evaluation periods specifies how many points the alarm examines. The SOA-C03 example uses two breaching points out of three five-minute periods. [AWS alarm evaluation](https://docs.aws.amazon.com/AmazonCloudWatch/latest/monitoring/alarm-evaluation.html)
- The AI-200 entry specifies Cosmos DB change-feed ordering per logical partition-key value. The two ServiceNow import entries now link directly to the import-set and transform-map teaching. [Azure Cosmos DB change feed](https://learn.microsoft.com/en-us/azure/cosmos-db/change-feed)
- The C professional guide distinguishes a data race from concurrent atomic accesses. The Kubernetes application developer guide uses the lifetime of an `emptyDir` to explain ephemeral storage. [SEI CERT C concurrency rule](https://cmu-sei.github.io/secure-coding-standards/sei-cert-c-coding-standard/rules/concurrency-con/con43-c/) · [Kubernetes ephemeral volumes](https://kubernetes.io/docs/concepts/storage/ephemeral-volumes/)

## Oracle Resource Manager job permissions

The OCI Architect Professional guide previously attributed Resource Manager jobs' target permissions to a “stack principal.” Oracle documents permissions needed by the identity running the job, including access to the target resources. The teaching paragraph and glossary now use the job as the unit of work and identify the authorization decision. [Oracle Resource Manager security](https://docs.oracle.com/en-us/iaas/Content/Security/Reference/resourcemanager_security.htm) · [Oracle worked Resource Manager example](https://docs.oracle.com/en/learn/oci-rm-automate-process/index.html)

## Review scope

This was an editorial review of the glossary changes. Product details relied on existing teaching passages and selective first-party checks. Access restrictions affected some references, including Fortinet product documentation and the IBM Db2 function-level page. The underlying guides retain their dated evidence and outstanding review findings. The work included no live vendor labs, exam delivery checks or human review. Historical full-guide audit hashes and dates retain their original meaning.
