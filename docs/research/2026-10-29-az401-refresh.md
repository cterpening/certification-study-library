# AZ-401 guide intake and source validation — October 29, 2026

## Why the guide was added

AZ-401 previously existed only as a research seed in config/certification-seeds.json and CERTIFICATIONS.txt. It was absent from config/exams.json, which intentionally lists only credentials with complete, source-validated guides and drives the public website. The current AZ-401 scope is sufficiently published to support a full guide, so this work promotes the seed to the site catalog.

## Technical and learning evidence

Technical research used official Microsoft Learn, Azure DevOps, Azure Monitor, Entra and GitHub documentation. It maps all five domains to role/decision explanations, failure boundaries and learner checks. The guide emphasizes MCP authorization, generated-workflow review, workload identity, protected-resource approvals, progressive deployment, scanner coverage, and independent verification of AI-assisted observability. Preview stages, plans, regions, clients, issuers and schemas are labeled volatile. No product behavior or cloud resource was executed.

Learning-resource research found an official seven-unit introduction to agentic DevOps, MicrosoftLearning’s public DevOps exercise collection, and Azure Pipelines documentation. Specific lab pages state duration and access requirements. The guide labels estimates, prerequisites and potential Azure/Copilot cost; it does not present a general orientation or lab set as full AZ-401 course coverage. A bounded search found no clearly named exam-specific course; this does not prove none exists.
