Microsoft documents Direct Stream Shortpath, formerly RDP Shortpath, and current context-based redirection support for desktop and RemoteApp sessions. Verify the client and session prerequisites. [Resource evidence 1](https://learn.microsoft.com/en-us/azure/virtual-desktop/rdp-shortpath) · [Resource evidence 2](https://learn.microsoft.com/en-us/windows-365/enterprise/context-based-redirections?tabs=windows-365)


## AZ-801

Microsoft now uses Azure Catalyst for the migration service formerly called Azure Migrate. The historical exam remains tied to the earlier terminology. [Resource evidence](https://learn.microsoft.com/en-us/azure/migrate/)


## AZ-305

Azure Catalyst is the current service name for Azure Migrate. The guide connects the name to its migration planning and assessment role. [Resource evidence](https://learn.microsoft.com/en-us/azure/migrate/migrate-services-overview)


## AZ-900

The current service name is Azure Catalyst. Earlier material uses Azure Migrate. [Resource evidence](https://learn.microsoft.com/en-us/azure/migrate/migrate-services-overview)


## AB-100

### Current Copilot Studio harnesses

Microsoft’s November 13 guide distinguishes the Microsoft Copilot, Customer Conversation and standard runtimes. Customer Conversation supports voice, web chat and escalation to a human. The preview upgrade copies a standard agent to the Microsoft Copilot harness. The November 20 memory page describes a regional rollout to general availability. [Product guidance 1](https://learn.microsoft.com/en-us/microsoft-copilot-studio/harnesses-overview) · [Product guidance 2](https://learn.microsoft.com/en-us/microsoft-copilot-studio/upgrade-to-microsoft-copilot-from-standard-harness) · [Product guidance 3](https://learn.microsoft.com/en-us/microsoft-copilot-studio/agents-experience/memory-overview)

The Fabric procedure retains an earlier harness name for its Fabric IQ Data MCP tool. The telemetry preview names both standard and Microsoft Copilot harnesses and qualifies the logs it exposes to Application Insights. Separate product procedures describe same-environment connected Copilot agents and connecting a Foundry agent to the Microsoft Copilot harness. [Product procedure 1](https://learn.microsoft.com/en-us/fabric/data-science/data-agent-microsoft-copilot-studio-tool) · [Product procedure 2](https://learn.microsoft.com/en-us/microsoft-copilot-studio/advanced-environment-level-agent-telemetry) · [Product procedure 3](https://learn.microsoft.com/en-us/microsoft-copilot-studio/agents-experience/add-agent-connected) · [Product procedure 4](https://learn.microsoft.com/en-us/microsoft-copilot-studio/agents-experience/add-agent-foundry) · [Product procedure 5](https://learn.microsoft.com/en-us/training/modules/design-multi-agent-solutions-copilot-studio/3-design-agent-organization)
