## Original examples and actual execution

Two original Python examples ran with Python 3.13.14. **34 local checks passed**, including eight real TCP/UDP exchanges bound only to `127.0.0.1` with OS-selected ports. The invented protocol returns PONG for a valid request and ERROR for a rejected request. That shows application rejection after successful transport communication; it does not implement DNS, DHCP, TLS or a production service. TCP uses explicit newline framing; a successful UDP loopback exchange is not proof of general delivery/order guarantees. Sockets close at the end of each case.

The other example calculates a `/26` address plan with 62 usable hosts, a 41-address pool, ten exclusions and one printer reservation, leaving 30 ordinary candidates before any leases. Cases cover boundaries, overlap, an accidental static-address collision, RFC1918 versus link-local classification, ideal RAID capacities and mirror failure placement. These are planning models, not executed DHCP, routing or physical-disk behavior. All eight complete hardware/platform labs remain proposed. No DNS service, firewall/NAT/Hyper-V settings, remote probes, TLS, Wi-Fi, printer, battery, PSU, disk array, mobile device or cloud service was changed or tested.
