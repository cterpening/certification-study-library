## DP-420

[Study guide](../../guides/DP-420-designing-and-implementing-cloud-native-applications-using-microsoft-azure-cosmos-db.md) · [Official objectives](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/dp-420)

[Credential](https://learn.microsoft.com/en-us/credentials/certifications/azure-cosmos-db-developer-specialty/) · [Exam route](https://learn.microsoft.com/en-us/credentials/certifications/exams/dp-420/)

**Product documentation.** For an Azure Cosmos DB for NoSQL consumer that needs deleted items or intervening versions, evaluate all versions and deletes mode. It requires continuous backup and exposes history only inside that backup retention window. Latest version mode serves workloads that need the latest available insert or update.

[Change Feed Modes - Azure Cosmos DB | Microsoft Learn](https://learn.microsoft.com/en-us/azure/cosmos-db/change-feed-modes)

All versions and deletes mode is documented as preview. An account feature or consumer chosen for one mode may differ from the other.

**Tutorial: Configure Microsoft Fabric mirrored database for Azure Cosmos DB.** The tutorial takes an existing Cosmos DB for NoSQL account through Fabric mirrored database creation, monitoring and analytical queries. About 25–45 minutes to map prerequisites, replication state and the analytical endpoint (editorial reading budget; deployment and data volume add time). It requires a suitable Fabric capacity and supported Cosmos DB configuration. Network/account limitations and access are part of the exercise. [Publisher resource](https://learn.microsoft.com/en-us/fabric/mirroring/azure-cosmos-db-tutorial)
