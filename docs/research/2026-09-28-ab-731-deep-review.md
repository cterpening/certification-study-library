## Material changes

- **Value and cost:** add original calculations for gross versus net capacity,
  review effort, realizable value and ROI; compare model routes by cost per
  accepted outcome. Avoid equating activity or estimated assisted hours with
  observed cash savings.
- **Licensing:** distinguish included/user entitlement, metered shared-data
  access and hosting. Work IQ API billing has its own boundary. Explain supported
  single-service resources, monthly/annual commitment differences, proration,
  renewal and overage with fictional demand scenarios.
- **Measurement:** explain the adoption score's 28-day window, 12-active-day
  target and licensed-user denominator. Contrast frequency, any-use share,
  correct task completion and value. Add a comparison-group calculation, explicit
  causal limitations, data freshness and coverage-versus-accuracy checks.
- **Current product boundaries:** retain unchanged exam terminology while
  explaining organizational Copilot naming changes and distinct harnesses. Scope
  EDP claims to actual web/model/agent data paths. Researcher model comparison does
  not prove independent factual verification or a uniform processing boundary.
- **Lifecycle and governance:** separate the September 2026 Image Analysis
  planning milestone from September 2028 API retirement. Add a scoped migration
  decision and do not generalize it to all Vision services. Clarify council,
  CoE, adoption-team and workload-owner responsibilities, enforceable policy
  records, exception expiry and incident suspension.
- **Learning:** add answers with reasoning to the original 36 checks plus 12 new
  ones. Two new labs produce a measurement decision memo and a process/lifecycle
  review rather than requiring a paid tenant or actual purchase.
