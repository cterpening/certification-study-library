## CISA

CISA-specific ISACA outline uses five domains. Both monitored objective text and status matched accepted records. [Exam evidence](https://www.isaca.org/credentialing/cisa/cisa-exam-content-outline)

NIST differentiates system contingency planning, emergency response, and organizational resilience when prioritizing recovery. [Technical reference](https://csrc.nist.gov/pubs/sp/800/34/r1/upd1/final)

ISACA offers a public CISA practice quiz for an initial audit-knowledge gap check. 15–25 minutes plus review, library estimate. [Preparation resource](https://www.isaca.org/credentialing/cisa/cisa-practice-quiz)

## CISM

ISACA sets governance 18%, risk 20%, program 33%, incident management 29% effective November 3, 2026. Architecture is newly explicit in governance strategy and program development. Format remains 150 questions. Monitor detected an objective-text difference. [Exam evidence 1](https://www.isaca.org/credentialing/cism/cism-exam-content-outline) · [Exam evidence 2](https://www.isaca.org/about-us/newsroom/press-releases/2026/isaca-updates-cism-exam-content-outline-factoring-in-todays-technologies-security-responsibilities)

NIST SP 800-61 Rev. 3 brings incident response into organizational cybersecurity risk management. [Technical reference](https://csrc.nist.gov/pubs/sp/800/61/r3/final)

ISACA maintains a free CISM practice-quiz landing page. Use management decisions as the context for reviewing missed topics. 15–25 minutes plus review, library estimate. [Preparation resource](https://www.isaca.org/credentialing/cism/cism-practice-quiz)

## CRISC

ISACA's CRISC-specific page maps four risk domains. Both monitored objective text and status matched accepted records. [Exam evidence](https://www.isaca.org/credentialing/crisc/crisc-exam-content-outline)

The CRISC practice-quiz route is available for a short risk-management self-check. 15–25 minutes plus review, library estimate. [Preparation resource](https://www.isaca.org/credentialing/crisc/crisc-practice-quiz)

## CC

ISC2 lists September 1, 2026 as the CC outline effective date. Both monitored objective text and status matched accepted records. [Exam evidence](https://www.isc2.org/certifications/cc/cc-certification-exam-outline)

## SSCP

ISC2 dates its SSCP exam outline October 1, 2025. Both monitored objective text and status matched accepted records. [Exam evidence](https://www.isc2.org/certifications/sscp/sscp-certification-exam-outline)

The flashcard page presents a form and privacy agreement; the deck contents require a separate step. 1–3 hours for first-pass review and targeted repetition, historical library estimate. [Preparation resource](https://cloud.connect.isc2.org/sscp-flashcards)

## CCSP

ISC2 dates the current CCSP outline August 1, 2026. Both monitored objective text and status matched accepted records. [Exam evidence](https://www.isc2.org/certifications/ccsp/ccsp-certification-exam-outline)

AWS KMS treats encryption context as authenticated, nonsecret metadata. It can appear unencrypted in CloudTrail, and decryption requires the same context. [Technical reference](https://docs.aws.amazon.com/kms/latest/developerguide/encrypt_context.html)

Six-domain CCSP study-resources page links the outline, self-paced training, and supplementary options. 10–20 minutes for selecting a route, editorial. [Preparation resource](https://www.isc2.org/certifications/ccsp/ccsp-self-study-resources)
