# GH-300: prove the tests can reject a bad suggestion

Allow 45–60 minutes. This implements the local fallback for Lab 6 in the [GH-300 guide](../../guides/GH-300-github-copilot.md). The [starter directory](https://github.com/cterpening/certification-study-library/tree/main/labs/gh-300) contains a contract, two prompts, an intentionally broken candidate, a reference, and a second mutation. Python 3.10 or later is sufficient.

## Establish the oracle first

An order subtotal is a nonnegative integer number of cents. Shipping costs 499 cents below 5,000 cents and is free at or above 5,000 cents. Reject booleans, floats, strings, nulls, collections and negative integers with `ValueError`. Tax, discounts, currency conversion and complete checkout-system behavior are outside scope.

Write these expectations before reading implementation files:

| Input | Expected |
|---|---|
| 0 or 4999 | 499 |
| 5000 or 5001 | 0 |
| A very large positive integer | 0 |
| -1 | `ValueError` |
| `True`, `False`, `50.0`, `"5000"`, `None`, `[]`, `{}` | `ValueError` |

`test_contract.py` runs seven tests, with invalid types checked as subtests. Its expected values come from this written requirement. Agreement between a suggestion and tests derived from that suggestion would not establish the correct boundary.

## Run the deliberate failures

From the repository root:

```console
python labs/gh-300/test_contract.py --implementation starter
python labs/gh-300/test_contract.py --implementation reference
python labs/gh-300/test_contract.py --implementation boolean_mutant
python labs/gh-300/compare.py
```

Run these commands individually if your shell stops on a nonzero exit. With the original files:

- **Starter:** exit 1, exactly the threshold test fails: `499 != 0` at 5000.
- **Reference:** exit 0, all seven tests pass.
- **Boolean mutation:** exit 1, the invalid-type test fails for both `True` and `False`. Python's `isinstance(value, int)` accepts booleans; this contract rejects them.
- **Comparison:** exit 0 only when each candidate has its expected result and there are no unrelated errors. It prints the actual results, including failure output. An import error does not count as a successful mutation check.

Work in a copy when repairing `starter.py`. After the fix, run its contract command again and expect all seven tests to pass. The comparison harness describes the **original intentionally broken** fixtures: it should reject a repaired starter because the expected deliberate failure is gone. Keep original fixtures available for reproducibility; do not alter the oracle to make a broken function pass.
