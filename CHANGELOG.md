# Changelog

Notable public changes are recorded here. The project uses semantic version tags for release checkpoints; guide freshness and exam status remain independently dated in the exam catalog and each guide.

## [0.1.0] — 2026-08-31

Initial public-library release:

- publish a searchable, responsive GitHub Pages site for 13 GitHub and Microsoft certification guides;
- add generated guide-start panels with prerequisites, reading estimates, weighted objectives, study paths, first-lab links, and correction links;
- promote GH-900 and GH-300 to **SOURCE-VALIDATED** with machine-readable review evidence;
- register 219 exact blueprint, product-documentation, training, and expert-resource sources;
- add weekly official-objective and source-health monitoring that creates review work without rewriting content automatically;
- add structured issue forms, security-reporting guidance, social preview metadata, JSON-LD, robots and sitemap support, and accessibility evidence; and
- document GitHub Pages publication and downstream work-mirror behavior.
