Normalized, paraphrased objective snapshot

1.0 Splunk Cloud Overview — 5%
1.1 Explain Splunk Cloud topology. 1.2 Distinguish customer/cloud-admin responsibilities. 1.3 Compare Splunk Cloud and self-managed Splunk Enterprise. 1.4 Compare the blueprint's Self-Service and Managed Cloud operating models.

2.0 Index Management — 5%
2.1 Explain an index. 2.2 Create Cloud indexes. 2.3 Delete indexed data/indexes through supported controls. 2.4 Monitor indexing activity.

3.0 User Authentication and Authorization — 5%
3.1 Administer roles. 3.2 Integrate supported LDAP, Active Directory, or SAML identity services.

4.0 Splunk Configuration Files — 5%
4.1 Identify configuration files/directories. 4.2 Apply precedence. 4.3 Distinguish index-time and search-time processing.

5.0 Getting Data in Cloud — 15%
5.1 Distinguish forwarder types. 5.2 Explain forwarder roles. 5.3 Configure forwarding to Splunk Cloud. 5.4 Test connectivity. 5.5 Apply optional forwarder settings.

6.0 Forwarder Management — 5%
6.1 Explain Deployment Server. 6.2 Explain forwarder management. 6.3 Configure deployment clients. 6.4 Manage forwarders through deployment apps.

7.0 Monitor Inputs — 15%
7.1 Explain the input pipeline. 7.2 Create file/directory monitors. 7.3 Apply optional monitor settings.

8.0 Network and Other Inputs — 10%
8.1 Create TCP/UDP inputs. 8.2 Create a basic scripted input. 8.3 Apply optional network-input settings. 8.4 Identify Windows input types/use cases. 8.5 Ingest through HTTP Event Collector.

9.0 Fine-tuning Inputs — 5%
9.1 Explain default input-phase processing. 9.2 Configure input-stage source type and character encoding behavior.

10.0 Parsing Phase and Data Preview — 10%
10.1 Explain default parsing. 10.2 Configure/optimize event boundaries. 10.3 Explain timestamp/time-zone extraction and assignment. 10.4 Validate event construction in Data Preview.

11.0 Manipulating Raw Data — 10%
11.1 Explain transforms definition/invocation. 11.2 Modify/reroute/filter raw data with props.conf and transforms.conf. 11.3 Modify raw text with SEDCMD.

12.0 Installing and Managing Apps — 5%
12.1 Explain supported app installation. 12.2 Explain private apps. 12.3 Manage Cloud apps through available self-service/support paths.

13.0 Working with Splunk Cloud Support — 5%
13.1 Isolate and document problems before escalation. 13.2 Follow the supported Splunk Cloud Support process.

The blueprint lists 60 questions and 75 total minutes, including 3 minutes for the exam agreement. It requires Splunk Core Certified Power User and warns that related topics may appear and guidelines can change without notice.
