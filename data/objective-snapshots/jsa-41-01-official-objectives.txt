Normalized, paraphrased objective snapshot

Block 1: Classless Objects — 11 items, 25%
1.1 Create and initialize objects with object-literal syntax.
1.2 Add, change, remove, and safely access ordinary and nested properties.
1.3 Select dot or bracket notation for ordinary, multi-word, dynamic, and computed keys.
1.4 Test property presence and enumerate own keys, values, and entries safely with in, for...in, and Object helpers.
1.5 Distinguish reference identity from structural or deep equivalence.
1.6 Explain reference copies; make shallow copies with Object.assign and spread; recognize deep-clone limitations.
1.7 Define object methods and reason correctly about this at the call site.
1.8 Define getters and setters that compute or validate state.
1.9 Configure property descriptors and apply preventExtensions, seal, and freeze.
1.10 Create objects through factories, constructor functions with new, and Object.create.
1.11 Explain the prototype chain and work with [[Prototype]], Function.prototype, and Object.setPrototypeOf.

Block 2: Classes and Class-Based Approach — 7 items, 23%
2.1 Declare classes and class expressions with constructors, fields, and methods; treat classes as values.
2.2 Instantiate classes with new and test prototype relationships with instanceof.
2.3 Initialize class fields in constructors or with field declarations.
2.4 Define computed or validated class state with getters and setters.
2.5 Implement inheritance and overriding with extends and super.
2.6 Define and call static properties and methods on the class.
2.7 Relate class syntax to constructor functions and prototype methods.

Block 3: Built-in Objects — 12 items, 27%
3.1 Convert, validate, and format numeric values with Number APIs.
3.2 Transform, split, search, replace, pad, trim, and compare strings.
3.3 Construct and modify Date values, distinguish local time from UTC, and measure elapsed time.
3.4 Create, merge, add, remove, slice, splice, spread, destructure, and iterate arrays.
3.5 Apply find, every, some, filter, sort, map, and reduce with correct callback behavior.
3.6 Create and manipulate Set collections and iterate their unique values.
3.7 Create and manipulate Map collections and iterate key-value entries.
3.8 Use plain objects as dictionary-like data structures.
3.9 Serialize supported JavaScript data to JSON and parse JSON text.
3.10 Apply common Math constants and functions for rounding, random values, ranges, powers, logs, and trigonometry.
3.11 Create regular expressions and use test, exec, match, search, and replace.
3.12 Explain how built-in prototypes can be extended and why doing so is risky.

Block 4: Advanced Functions — 10 items, 25%
4.1 Use default and rest parameters, spread arguments, destructuring, and object-based named-parameter patterns.
4.2 Explain lexical closures and create immediately invoked function expressions.
4.3 Control call context and forward arguments with call, apply, and bind.
4.4 Build decorators and higher-order functions that accept or return functions.
4.5 Create generators, iterators, and custom iterable objects.
4.6 Organize asynchronous callback flows and propagate errors deliberately.
4.7 Create promises and handle fulfillment, rejection, and cleanup with then, catch, and finally.
4.8 Chain promises and coordinate work with Promise.all, Promise.any, and Promise.race.
4.9 Write async functions, await promises, and handle asynchronous errors with try/catch.
4.10 Make asynchronous HTTP requests with XMLHttpRequest and Fetch.

Passing requirement: cumulative normalized score of at least 70%.
