Block 1: Core Software Testing Concepts — 6 items, 17.1%
1.1 Definition and purpose of testing.
1.2 Relationships among errors, defects and failures.
1.3 Testing in SDLC: risk, economics, Waterfall/Agile/DevOps, shift-left, continuous testing, collaboration.
1.4 Testing principles and risk/context-based workflow. (Official heading incorrectly says “Explain how data is stored and organized.”)

Block 2: Software Testing Types, Levels, and Processes — 8 items, 22.9%
2.1 Manual/automated and functional/non-functional testing.
2.2 Unit, integration, system and acceptance levels.
2.3 Test pyramid.
2.4 Planning, design, environment, execution, reporting, closure.
2.5 Plans, cases, scenarios and reports.
2.6 Dummies, stubs, fakes, spies and mocks.

Block 3: Static Analysis, Dynamic Testing, and Code Refactoring — 10 items, 28.6%
3.1 Reviews, walkthroughs, inspections and static tools.
3.2 Dynamic levels/techniques.
3.3 Code quality, PEP 8 and linters.
3.4 Pylint/Flake8 and refactoring findings.
3.5 Line, branch and method coverage.
3.6 Behavior-preserving refactoring, AAA, DRY and KISS.

Block 4: Debugging, Assertions, and Testing Techniques — 11 items, 31.4%
4.1 Print/IDE debugging, breakpoints and stepping.
4.2 Assertions and expected conditions.
4.3 Logging and DEBUG/INFO/WARNING/ERROR/CRITICAL.
4.4 White-box statement, branch, path and loop testing.
4.5 Black-box equivalence partitions, boundaries, decision tables and state transitions.
4.6 Error guessing, exploratory and checklist-based testing.
