Palo Alto Networks Certified XSOAR Engineer objective snapshot
Source: https://www.paloaltonetworks.com/content/dam/pan/en_US/assets/pdf/datasheets/education/xsoar-engineer-datasheet.pdf
Datasheet: August 2025
Verified: 2026-09-02

1. Planning, Installation, and Maintenance (14%)
1.1 Demonstrate knowledge of planning/configuring system authentication and authorization
1.2 Explain planning/deploying engines
1.3 Explain planning/managing a dev/prod deployment
1.4 Manage Marketplace pack installation and version updates
1.5 Configure and troubleshoot integration instances
1.6 Maintain and troubleshoot the system

2. Use Case Planning and Development (22%)
2.1 Demonstrate understanding of incident and indicator lifecycles
2.2 Explain field and layout configuration
2.3 Demonstrate understanding of classifier and mapper configuration
2.4 Identify incident-creation methods
2.5 Identify incident preprocessing and postprocessing functions
2.6 Demonstrate knowledge of incident-type playbooks, layouts, and SLAs
2.7 Explain list configuration and management

3. Playbook Development (30%)
3.1 Explain playbook task input/output configuration and results
3.2 Explain referencing/manipulating context data for automation workflow
3.3 Identify playbook task types
3.4 Demonstrate sub-playbook input/output/looping configuration
3.5 Apply filters and transformers to playbook-task data
3.6 Apply playbook debugger in development/troubleshooting
3.7 Identify built-ins, commands, and scripts
3.8 Create/apply automation scripts
3.9 Create/manage jobs

4. Incident Interactions and Reporting (16%)
4.1 Explain incident states and actions
4.2 Demonstrate understanding of War Room activities
4.3 Explain incident relationships
4.4 Demonstrate dashboard/report configuration

5. Threat Intelligence Management (18%)
5.1 Identify threat-intelligence features
5.2 Explain indicator-creation methods
5.3 Explain indicator configuration
5.4 Explain indicator relationships
5.5 Demonstrate indicator enrichment and source reliability
5.6 Explain threat-intel sharing with external security services
5.7 Demonstrate indicator-exclusion-list configuration/management
