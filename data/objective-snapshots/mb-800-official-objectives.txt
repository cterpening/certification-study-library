Exam MB-800: Microsoft Dynamics 365 Business Central Functional Consultant
Official objective baseline: Skills measured as of June 30, 2026
Source: https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/mb-800
Captured: 2026-09-01

Skills at a glance

Set up Business Central (20–25%)
Configure financials (30–35%)
Configure sales and purchasing (10–15%)
Perform Business Central operations (30–35%)

Set up Business Central
- Create/configure a company: Assisted Setup, worksheet/package, opening balances, migration
- Manage security: profiles/users, permissions/sets, filters, security groups and auditing
- Set up core functionality: report layouts, job queues, number series, Copilot and agents
- Set up dimensions: values, global/shortcut/default dimensions, blocking, priorities
- Manage approvals: native workflows, notifications, approval users and workflow groups

Configure financials
- Set up finance: G/L setup, periods, terms, deferrals, currencies/rates and payment methods
- Manage chart of accounts: G/L accounts, categories/subcategories, reporting and allocations
- Set up specific/general/inventory posting groups, general posting setup and multiple groups
- Set up bank accounts, journal templates/number series, batches and recurring templates
- Set up payables: vendors, purchase/payables setup, payment journals and entry relationships
- Set up receivables: customers, sales/receivables setup, cash receipts, payment registration and entry relationships
- Configure fixed assets: settings/books/classes/subclasses, assets/components and depreciation methods

Configure sales and purchasing
- Set up inventory: setup, item categories/attributes/UOM/variants, locations, entry relationships, costing and SKUs
- Configure customer/vendor sales and purchasing master-data settings
- Manage purchase/sales prices and line/invoice discounts

Perform Business Central operations
- Basic tasks: design/customize/personalize, filters, related entries, inspect, Edit in Excel and analysis mode
- Purchases: quotes/orders, receipt/over-receipt/reversal/invoice, recurring/blanket lines and deferrals
- Sales: quotes/order/invoice, availability, shipment/reversal/invoice, recurring/blanket lines and deferrals
- Financial documents: invoices/credit memos, combined receipts/shipments, corrections, release/reopen and prepayments
- Journals/payments: payment/receipt/registration, apply/unapply, reverse, bank reconcile, recurring/allocation, FX adjust, dimension correction and G/L revaluation
- Fixed assets: acquisition, depreciation and disposal
- Inventory: receipts, shipments, transfers, cost adjustment, counts and reclassification

Change log summary

The June 30, 2026 update decreases setup weighting, increases operations,
removes the standalone integrations group, substantially revises core setup and
basic tasks, adds Copilot/agent enablement, and adds inventory transactions.
