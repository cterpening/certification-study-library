Normalized, paraphrased objective snapshot

Block 1: HTML Fundamentals — 10 items, 25%
1.1 Build a standards-mode HTML document with correctly ordered doctype, html, head, and body.
1.2 Apply charset, viewport, title, description, favicon, social, and robots metadata appropriately.
1.3 Produce well-formed, nested, semantic markup without obsolete presentation elements or duplicate IDs.
1.4 Select header, nav, main, section, article, aside, and footer by content meaning.
1.5 Organize content with paragraphs, lists, description lists, and accessible data tables.
1.6 Use a logical heading hierarchy, thematic breaks, and meaningful line breaks.
1.7 Embed responsive images, audio, and video with suitable alternatives, controls, captions, and loading behavior.
1.8 Embed external content through responsive, titled iframes with appropriate security controls.
1.9 Construct forms with suitable controls, labels, groups, submission settings, and native constraints.
1.10 Build clear navigation using descriptive link text, useful URLs, relative/absolute references, skip links, and safe new-window behavior.

Block 2: CSS Fundamentals — 9 items, 22.5%
2.1 Write valid CSS with type, class, ID, attribute, pseudo-class, and pseudo-element selectors and suitable values/units.
2.2 Resolve the cascade through source order, origin, importance, specificity, and inheritance.
2.3 Apply typography, color, backgrounds, borders, sizing, spacing, and border-box consistently.
2.4 Use display, sizing functions, overflow, aspect ratio, logical properties, effects, and custom properties appropriately.
2.5 Build transitions and keyframe animations with performant properties and reduced-motion alternatives.
2.6 Distinguish static, relative, absolute, fixed, and sticky positioning; reason about containing and stacking contexts.
2.7 Use a CSS framework such as Bootstrap without making overrides fragile.
2.8 Use Sass or Less variables, nesting, mixins/functions, modules/partials, compilation, and source maps at a basic level.
2.9 Improve CSS performance and maintainability through minification, caching, pruning, and shallow selectors.

Block 3: Integrating HTML and CSS — 10 items, 25%
3.1 Link external stylesheets and embed internal styles with deliberate order and media targeting.
3.2 Apply inline styles only for justified one-off/dynamic cases and understand their specificity cost.
3.3 Resolve style conflicts with low-specificity classes, naming conventions, tokens, layers, and limited !important use.
3.4 Organize CSS, scripts, images, fonts, source, and build output into predictable paths.
3.5 Construct responsive, readable form layouts with Flexbox/Grid and reusable style tokens.
3.6 Combine native form constraints with small scripts where needed; expose errors accessibly.
3.7 Style controls and interactions with clear hover, focus-visible, disabled, keyboard, contrast, touch, and motion states.
3.8 Validate HTML and CSS and use linting/autoprefixing where appropriate.
3.9 Diagnose cascade and specificity conflicts from computed styles and prevent breakpoint/theme regressions.
3.10 Use browser developer tools for live inspection, box/layout overlays, responsive testing, and rendering analysis.

Block 4: Responsive Web Design and Layout Techniques — 5 items, 12.5%
4.1 Build mobile-first layouts with media queries, fluid grids, flexible images, responsive sources, and adaptive scales.
4.2 Configure the viewport and design touch-friendly, keyboard-accessible navigation without hover dependence.
4.3 Select Flexbox for one-dimensional alignment and Grid for two-dimensional layout; use gaps and semantic markup.
4.4 Test breakpoints and devices; apply progressive enhancement, @supports fallbacks, intrinsic sizing, and compatibility tooling.
4.5 Optimize media/assets with lazy loading, correct sizing/formats, minification, caching, resource hints, and performance budgets.

Block 5: Accessibility, Usability, and Best Practices — 6 items, 15%
5.1 Provide text alternatives, captions/transcripts, semantic landmarks, keyboard/focus support, contrast, labelled forms, announced errors, and reduced-motion behavior.
5.2 Improve information architecture, navigation, typography, feedback, and flows through lightweight usability evaluation.
5.3 Separate structure, presentation, and behavior and use reusable components, tokens, naming, version control, and documented conventions.
5.4 Validate across browsers/devices and audit accessibility, internationalization, print, and Core Web Vitals under a performance budget.
5.5 Apply on-page and technical SEO with metadata, headings, semantics, links, image alternatives, sitemaps, robots, canonical URLs, structured data, performance, and mobile support.
5.6 Define meaningful analytics KPIs/events and dimensions while respecting privacy, consent, and data-minimization requirements.

Passing requirement: cumulative normalized score of at least 75%.
