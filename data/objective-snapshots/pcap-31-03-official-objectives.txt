Section 1: Modules and Packages — 6 items, 12%
1.1 Import and use modules and packages: import variants, qualification, dir(), sys.path.
1.2 Use math: ceil(), floor(), trunc(), factorial(), hypot(), sqrt().
1.3 Use random: random(), seed(), choice(), sample().
1.4 Discover host properties with platform.
1.5 Create and use modules/packages: __pycache__, __name__, visibility convention, __init__.py, search paths, nesting.

Section 2: Exceptions — 5 items, 14%
2.1 Handle Python-defined exceptions: try/except, hierarchy, raise, assert, args, else, finally.
2.2 Define custom exceptions and integrate them into a hierarchy.

Section 3: Strings — 8 items, 18%
3.1 Character representation: ASCII, Unicode, UTF-8, code points, escapes.
3.2 String operations: ord(), chr(), indexing, slicing, immutability, iteration, comparison, membership.
3.3 String methods: is* methods, join(), split(), strip(), index(), find(), rfind(), sorted().

Section 4: Object-Oriented Programming — 12 items, 34%
4.1 OOP concepts: class, object, property, method, encapsulation, inheritance.
4.2 Instance/class variables, __dict__, private components and name mangling.
4.3 Methods and self.
4.4 Introspection: hasattr(), __name__, __module__, __bases__.
4.5 Single/multiple inheritance, isinstance(), identity, overriding, polymorphism, __str__(), diamond problems.
4.6 Constructors and object initialization.

Section 5: Miscellaneous — 9 items, 22%
5.1 Conditional and nested list comprehensions.
5.2 Lambdas, higher-order functions, map(), filter().
5.3 Closures.
5.4 I/O terminology: modes, streams, handles, text/binary.
5.5 File I/O: open(), errno, close/read/write/readline/readlines, bytearray buffers.
