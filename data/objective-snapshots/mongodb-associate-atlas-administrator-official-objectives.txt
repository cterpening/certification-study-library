Public official learning-path scope (unweighted; detailed exam objectives require free enrollment)

MongoDB Overview
Understand the document model, dynamic schema, distributed architecture, and nested/semi-structured data.

CRUD Operations in MongoDB
Perform create, read, update, and delete operations.

Fundamentals of Data Transformation
Build aggregation pipelines to process, transform, and analyze data.

Indexing Design Fundamentals
Design indexes that improve supported queries and reduce resource consumption.

Query Optimization
Diagnose and improve slow or inefficient queries.

Sharding Strategies
Design, implement, and manage sharded clusters for scale and performance.

Monitoring Tooling
Use monitoring tools, interpret CPU/query metrics, and configure alerts.

Performance Tools and Techniques
Use profiling, slow-query analysis, index/cache evidence, and system metrics.

Data Resilience: Atlas
Design resilient Atlas deployments with failover, backups, security, compliance, and workload isolation.

Cluster Reliability
Diagnose and resolve replication, sharding, availability, and performance issues.

Secure MongoDB Atlas: Authentication and Authorization
Configure authentication and authorization for Atlas and database access.

Networking Security: Atlas
Use IP access lists, peering, private endpoints, and encryption in transit.

Encryption at Rest
Configure Atlas encryption at rest and customer-managed key integration where required.
