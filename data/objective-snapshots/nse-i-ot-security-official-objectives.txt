Description
The Industry Certification in OT Security validates the ability to design, deploy, and monitor advanced Fortinet security solutions for operational technology environments.

Program requirements
- Hold NSE 4 FortiOS certification.
- Hold NSE 5 or NSE 6 certification.
- Hold NSE 7 certification in the same track as the NSE 5 or NSE 6.
- Pass the proctored OT Security Architect exam within 2 years of the last prerequisite exam.
- Certification is active for 2 years from the industry exam or the last prerequisite exam, whichever is later.

Qualifying industry exam
Fortinet NSE I - OT Security Architect

Exam contract
- 70 minutes; 35–40 questions; English; status Available

Product baseline
- FortiOS 7.6
- FortiAnalyzer 7.6
- FortiSIEM 7.4
- FortiNAC 7.6

Published objective groups and tasks

Asset management (15–25%)
- Explain OT standard and Fortinet compliance
- Fortinet Security Fabric for an OT network
- Implement device detection on FortiGate and FortiNAC

Network access control (25–35%)
- Explain OT Ethernet concepts
- Configure network segmentation schemas
- Configure network access authentication

Network security (25–35%)
- Configure security inspections for industrial protocols
- Configure virtual patching
- Configure automation

Monitoring and risk assessment (20–30%)
- Create FortiAnalyzer event handlers
- Perform risk assessment and management
- Analyze security reports from FortiAnalyzer

Objective weight ranges overlap and should not be normalized into point weights.
