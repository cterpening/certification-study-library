Exam: Splunk Core Certified User

Normalized, paraphrased objective snapshot

1.0 Splunk Basics — 5%
1.1 Identify the principal Splunk platform components.
1.2 Explain common uses of the Splunk platform.
1.3 Define the purpose of a Splunk app.
1.4 Customize user-level settings.
1.5 Navigate the Splunk user interface.

2.0 Basic Searching — 22%
2.1 Run basic searches.
2.2 Select an appropriate search time range.
2.3 Interpret the contents of search results.
2.4 Refine a search.
2.5 Use the timeline.
2.6 Inspect and work with individual events.
2.7 Control a search job.
2.8 Save or export search results appropriately.

3.0 Using Fields in Searches — 20%
3.1 Explain fields and field-value pairs.
3.2 Use fields to retrieve and filter events.
3.3 Use the fields sidebar to inspect/select fields.

4.0 Search Language Fundamentals — 15%
4.1 Apply foundational SPL commands and sound search practices.
4.2 Explain how commands form a search pipeline.
4.3 Restrict searches to appropriate indexes.
4.4 Use table, rename, fields, dedup, and sort.

5.0 Using Basic Transforming Commands — 15%
5.1 Summarize common values with top.
5.2 Summarize uncommon values with rare.
5.3 Calculate grouped statistics with stats.

6.0 Creating Reports and Dashboards — 12%
6.1 Save a search as a report.
6.2 Edit a report.
6.3 Create a report that displays a statistical table.
6.4 Create a report that displays a chart visualization.
6.5 Create a dashboard.
6.6 Add a report to a dashboard.
6.7 Edit a dashboard.

7.0 Creating and Using Lookups — 6%
7.1 Explain the purpose of lookups.
7.2 Interpret a lookup-file example.
7.3 Upload/create a lookup table file and define it for search use.
7.4 Configure an automatic lookup.
7.5 Invoke a lookup in a search.

8.0 Creating Scheduled Reports and Alerts — 5%
8.1 Explain scheduled reports.
8.2 Configure a report schedule.
8.3 Explain alert purpose and behavior.
8.4 Create an alert.
8.5 Inspect fired alerts.

The blueprint lists 60 questions and 60 total minutes, including 3 minutes for the exam agreement. It says that related topics may appear and that the guidelines may change without notice. It lists no prerequisite exams.
