Palo Alto Networks Certified Security Operations Architect objective snapshot
Source: https://www.paloaltonetworks.com/content/dam/pan/en_US/assets/pdf/datasheets/education/secops-architect-datasheet.pdf
Datasheet: February 2026
Verified: 2026-09-02

1. Business Alignment and Strategy (22%)
1.1 Design Cortex-tenant data residency, retention, and access-control models to meet standards (GDPR, PCI, local privacy laws)
1.2 Assess architecture considerations aligned to product licenses
1.3 Define SOC performance metrics and reporting requirements

2. Platform and Data Architecture (49%)
2.1 Plan data-pipeline architecture using tools (for example, Cribl)
2.2 Design tenant structure, multitenancy hierarchies, and component placement for deployment scenarios
2.2.1 Broker VM architecture and components
2.2.2 XDR Collector deployment
2.2.3 Engine deployment
2.3 Define strategy for data sources, integrations, and feeds and select onboarding methods

3. Automation and Detection Strategy (29%)
3.1 Define strategy based on data sources, business alignment, organization strategy, and best practice
3.1.1 Detection use cases
3.1.2 Automation use cases (data sources, integrations)
3.2 Plan integration of legacy-SIEM detection rules and automation use cases into Cortex XSIAM
3.3 Design development/production tenant architecture and associated impacts
3.4 Define automation strategies for agentic versus playbook capabilities
