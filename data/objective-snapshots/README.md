# Official objective snapshots

The normalized objective text and status JSON files are generated from the Microsoft Learn study-guide URLs configured in `config/exams.json`. The status snapshots record published skills-version labels and explicit future-update or retirement announcements. The initial GitHub, AI-103, and AB-100 snapshots were retrieved on August 30, 2026.

Future runs compare live objectives with these committed baselines. Do not treat a generated replacement as trusted until its pull request has been checked against the official page.
