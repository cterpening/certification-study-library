Block 1: Security Essentials — 10 items, 22%
1.1 CIA triad. 1.2 Threat/risk classification and malware/attack protection. 1.3 Consequences of loss, theft and modification. 1.4 Unavailability impacts. 1.5 Legal/regulatory/trade-secret consequences. 1.6 Security communication/collaboration.

Block 2: IT Systems Security — 12 items, 27%
2.1 Continuous security, technical/organizational safeguards and secure development. 2.2 Hardening. 2.3 Ports/protocols/services and network settings. 2.4 Authentication, authorization, passwords and MFA. 2.5 Cloud-storage, SaaS and remote-access risks/practices.

Block 3: Python for Security Operations — 13 items, 29%
3.1 Authorized assessments, basic vulnerability checks and ethical information gathering. 3.2 Website checks, process monitoring, automated responses and subprocess/OS commands. 3.3 Log correlation. 3.4 Structured reports and result documentation. 3.5 Scheduled checks, backup verification and chained tasks.

Block 4: Secure Development and Implementation in Python — 10 items, 22%
4.1 Linters/static analysis; input validation/sanitization; output encoding/escaping; safe file/exception handling; secret configuration. 4.2 cryptography, paramiko, and secure document/file handling. 4.3 Hash/checksum integrity verification.
