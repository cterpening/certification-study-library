Block 1: Data Acquisition and Pre-Processing — 14 items, 29.2%
1.1.1 Compare collection methods; 1.1.2 aggregate multiple sources; 1.1.3 storage solutions.
1.2.1 Structured/unstructured data; 1.2.2 erroneous and missing data; 1.2.3 normalization/scaling/encoding; 1.2.4 cleaning and standardization.
1.3.1 Validation methods; 1.3.2 integrity rules.
1.4.1 File formats; 1.4.2 dataset access/management; 1.4.3 databases/APIs/web extraction and ethical scraping; 1.4.4 spreadsheet practices; 1.4.5 preprocessing, shape and train/test splits.

Block 2: Programming and Database Skills — 16 items, 33.3%
2.1.1 Python syntax/control; 2.1.2 functions; 2.1.3 data-science ecosystem; 2.1.4 core collections; 2.1.5 PEP 8/257.
2.2.1 Imports and pip; 2.2.2 exceptions.
2.3.1 Classes; 2.3.2 composition/inheritance/polymorphism; 2.3.3 identity/equality.
2.4.1 SELECT, JOIN, WHERE, GROUP BY, HAVING, ORDER BY, LIMIT; 2.4.2 SQL CRUD; 2.4.3 Python database connections; 2.4.4 parameterized queries; 2.4.5 SQL/Python types; 2.4.6 injection prevention.

Block 3: Statistical Analysis — 4 items, 8.3%
3.1.1 Central tendency, spread, distributions and confidence; 3.1.2 outliers, correlation and plots.
3.2.1 Bootstrapping; 3.2.2 linear/logistic regression, assumptions, fitting and interpretation.

Block 4: Data Analysis and Modeling — 9 items, 18.8%
4.1.1 Pandas cleaning; 4.1.2 merge/join/pivot/reshape; 4.1.3 Series/DataFrame; 4.1.4 loc/iloc/slicing; 4.1.5 NumPy operations/broadcasting; 4.1.6 groupby/pivot/crosstab.
4.2.1 Descriptive statistics; 4.2.2 test datasets; 4.2.3 supervised learning, accuracy, over/underfitting and bias-variance.

Block 5: Data Communication and Visualization — 5 items, 10.4%
5.1.1 Matplotlib/Seaborn; 5.1.2 representation tradeoffs; 5.1.3 labels/annotations/refinement.
5.2.1 Audience-aware communication; 5.2.2 evidence-backed findings.
