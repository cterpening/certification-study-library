Exam MB-820: Microsoft Dynamics 365 Business Central Developer
Official objective baseline: Skills measured as of June 10, 2025
Source: https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/mb-820
Captured: 2026-09-01

Skills at a glance

Describe Business Central (10–15%)
Install, develop, and deploy for Business Central (10–15%)
Develop by using AL objects (35–40%)
Develop by using AL (15–20%)
Work with development tools (10–15%)
Integrate Business Central with other applications (10–15%)

Describe Business Central
- Architecture: components/capabilities, core/extensions, customization updates, online/on-premises
- Apps: base/system apps, app functionality and AppSource process

Install, develop, and deploy
- Development environment: describe/install/configure, extension configuration and multi-extension workspace
- Extension lifecycle: create/modify, debug, deploy, multilanguage and maintenance

Develop by using AL objects
- Tables/pages: Role Centers, page types, page/table extensions and enums
- Reports: substitution, layouts, documents/data model/language/triggers/functions/processing/request page
- XMLports: properties, nodes and AL use
- Codeunits: create/access, events/triggers, interfaces and install/upgrade codeunits
- Entitlements/permission sets: create/extend, inherent permissions and troubleshooting
- Queries: link/join/filter, query versus records, aggregation and reports

Develop by using AL
- UI/onboarding: profiles, views, user assistance, Assisted Setup, teaching tips/tours/checklist
- Standards: data process, functional table types, documents and master-data patterns
- AL: procedures, data types, files, data manipulation, expressions, built-ins/statements, variables, errors and access modifiers

Work with development tools
- Tests: applications, Test Toolkit, test codeunits and procedures
- Telemetry: configure, monitor/analyze and custom signals

Integrate with other applications
- REST clients: HTTP classes, external send/receive and JSON
- APIs: create/use APIs, OData bound/unbound actions and Read Scale-Out

Change log summary

The June 10, 2025 change log records minor development-environment changes and
a major revision to API implementation. No newer baseline is published, so
runtime, AppSource, testing, telemetry, authentication and API implementation
details require current documentation checks.
