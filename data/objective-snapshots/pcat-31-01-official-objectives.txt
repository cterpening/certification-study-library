Block 1: Software Testing Essentials — 7 items, 16.7%
1.1 Testing traits; 1.2 unit/integration/system/acceptance levels; 1.3 error/defect/bug/failure; 1.4 seven testing principles; 1.5 entry/exit conditions; 1.6 test pyramid; 1.7 coverage/dead code.

Block 2: Test Automation and Code Refactoring — 4 items, 9.5%
2.1 Automation purpose/benefits; 2.2 refactoring loop; 2.3 AAA; 2.4 DRY/KISS.

Block 3: Assertions, Context Managers, Decorators, and Python Methods — 5 items, 11.9%
3.1 Assertions, optimization, test doubles; 3.2 with/code-sandwich; 3.3 function decorators/stacking; 3.4 class decorators; 3.5 instance/static/class methods.

Block 4: Foundations of Unit Testing — 12 items, 28.6%
4.1 FIRST; 4.2 xUnit cases/suites/fixtures/runner/separation; 4.3 execution; 4.4 structure/naming; 4.5 specialized unittest assertions; 4.6 tests as documentation; 4.7 AAA; 4.8 TestCase, setUp, tearDown, discovery.

Block 5: Advanced Unit Testing Techniques — 11 items, 26.2%
5.1 Method/class/module fixtures; 5.2 parameterized unit tests; 5.3 skip/skipIf/expectedFailure; 5.4 selective execution; 5.5 Mock/MagicMock; 5.6 patch; 5.7 exception testing.

Block 6: Test-Driven and Behavior-Driven Development — 3 items, 7.1%
6.1 TDD principles/tradeoffs; 6.2 red-green-refactor; 6.3 BDD and Given/When/Then.
