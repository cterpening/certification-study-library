Exam MB-500: Microsoft Dynamics 365 Finance and Operations Apps Developer
Official objective baseline: Skills measured as of January 30, 2026
Source: https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/mb-500
Captured: 2026-09-01

Skills at a glance

Plan the architecture and solution design (5–10%)
Apply developer tools (5–10%)
Design and develop AOT elements (15–20%)
Develop and test code (20–25%)
Implement reporting (10–15%)
Integrate and manage data solutions (15–20%)
Implement security and optimize performance (10–15%)

Plan architecture and solution design
- Differentiate cloud and on-premises; extend into Microsoft ecosystem
- Manage environments/issues/assets/packages through LCS
- Manage UDE developer environments through PPAC and environments through Implementation portal

Apply developer tools
- Create/manage extension models and metadata; synchronize database; create elements; debug
- Use Azure DevOps version control: create/review/check in, artifacts, branches/merges/conflicts, choose system, CI/CD

Design and develop AOT elements
- Create/extend forms, menus/menu items, labels
- Create/extend tables, views, queries, maps, and data entities
- Create/extend classes, event handlers, attributes, and modifiers

Develop and test code
- X++ constructs, CRUD, global functions, and best-practice warnings
- Scope, inheritance/abstraction, QueryBuilder, attributes, CoC, extensibility/breaking changes, events/delegates
- SysOperation, workflow, SysExtensionSerializer
- SysTest/Task recorder unit tests and Test Explorer

Implement reporting
- Report data sources/supporting classes, security, datastores/tool choice
- SSRS, Power BI, Excel, and Electronic Reporting
- Workspaces, KPIs, drill-through, and Power BI visualizations

Integrate and manage data solutions
- Contrast patterns/APIs and sync/async
- REST/SOAP, ER integrations, custom services, Batch OData
- Entity import/export, composite/aggregate entities, monitoring/change tracking/projects/sequencing/recurring jobs/mapping
- Dual-write, virtual entities, Power Platform, Excel OData, business events, Key Vault

Implement security and optimize performance
- Roles/duties/privileges/permissions, security policies, XDS
- Table/form/global caching, singleton, temporary tables, set/row queries, query/scope/concurrency optimization
- Traces/Trace Parser, entity/query/batch/report optimization, Async/Sandbox, indexes

Change log summary

The January 30, 2026 change log makes major changes to ALM/LCS and data
management, adds current UDE/PPAC and Implementation portal responsibilities,
decreases developer-tools weighting, increases code/test weighting, and revises
most implementation groups.
