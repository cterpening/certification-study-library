Fortinet NSE 3 in Cybersecurity published-course snapshot

Verified: 2026-09-02

Certification requirement
- Complete the FortiGate Operator course and pass its online exam.
- Fortinet states the awarded certification is active for 2 years from course completion.

Published course baseline
- Product version: FortiOS 7.6
- Estimated duration: 8 hours
- Format: self-paced online

Published course agenda (no weights published)
1. FortiGate Overview
2. How to Access your FortiGate
3. Configuring System Settings and Basic Networking
4. Firewall Policies
5. Logging Events
6. Authenticating Network Users
7. Inspect SSL Traffic
8. Blocking Malware
9. Control Web Access Using Web Filtering
10. Configuring the FortiGate Intrusion Prevention System
11. Controlling Application Access
12. Securing Remote Access with ZTNA
13. Creating IPsec Virtual Private Networks
14. FortiGate System Maintenance and Monitoring
15. Configuring the Fortinet Security Fabric
16. FortiGate High Availability (HA)
17. Configuring FortiLink
18. Securing Public and Private Clouds
19. FortiCare
20. FortiCloud

Published course objectives
- Configure the most common high-level FortiGate features.
- Connect remote users securely using VPNs.
- Restrict access to network resources.
- Monitor essential indicators and logs.
- Perform basic system maintenance.

Boundary note
- Fortinet does not publish weighted domains, item count, or a time limit for this course-based online assessment.
