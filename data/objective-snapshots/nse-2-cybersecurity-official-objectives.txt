Fortinet NSE 2 in Cybersecurity published-course snapshot
Source: https://training.fortinet.com/local/staticpage/view.php?page=nse_2
Course source: https://training.fortinet.com/local/staticpage/view.php?page=library_introduction-to-next-generation-firewall
Verified: 2026-09-02

Certification requirement
- Complete Introduction to the Next Generation Firewall and pass the online exam presented at the end of the course.
- Fortinet states the awarded certification is active for 2 years from course completion.

Published course agenda (no weights published)
1. What is Next Generation Firewall
2. How Firewall Policies Work
3. User Authentication in NGFW
4. Blocking Malware
5. Controlling Web Access with Web Filtering
6. Intrusion Prevention System and Application Control
7. Connecting Multiple Locations Securely
8. Secure SD-WAN
9. SASE

Published course objectives
- Describe what an NGFW is and how it protects networks, applications, and services.
- Explain how the main features of an NGFW work.
- Explain how secure network models and technologies such as SD-WAN and SASE can enhance cybersecurity.

Boundary note
- Fortinet does not publish weighted domains, item count, time limit, or a standalone proctored-exam blueprint for this online course assessment.
