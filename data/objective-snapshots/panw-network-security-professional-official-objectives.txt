Palo Alto Networks Certified Network Security Professional objective snapshot

Datasheet: June 2026
Verified: 2026-09-02

1. Network Security Fundamentals (17%)
1.1 Application-layer inspection for Strata and SASE
1.2 Slow-path and fast-path packet inspection
1.3 SSL Forward Proxy, SSL Inbound Inspection, SSH Proxy, and no-decrypt choices
1.4 Content-ID, Zero Trust, User-ID, Device-ID, and zones for hardening

2. NGFW and SASE Solution Functionality (13%)
2.1 Cloud NGFW, PA-Series, CN-Series, and VM-Series: perimeter/core, zones/segmentation, HA, security/NAT policy, monitoring/logging
2.2 Prisma SD-WAN: optimization, path/NAT policy, zone firewall, monitoring/logging
2.3 Prisma Access: remote users/networks, public/private apps, security/NAT policy, monitoring/logging
2.4 Panorama and Strata Cloud Manager management functions

3. Platform Solutions, Services, and Tools (30%)
3.1 NGFW/Prisma SASE efficacy through security/NAT policy, User-ID, App-ID, decryption, monitoring/logging
3.2 CDSS: IoT Security, Enterprise DLP, SaaS Security, PAN-OS SD-WAN, Premium GlobalProtect, Advanced WildFire, Advanced Threat Prevention, Advanced URL Filtering, Advanced DNS Security
3.3 AIOps alignment to best practices, dashboards, BPA, and administration
3.4 Next-Generation Trust Security for governance, trust relationships, and adaptive decisions
3.5 Quantum risks and platform post-quantum/hybrid-cryptography readiness
3.6 AI-use/data/access/threat risks and platform discovery, monitoring, control, and protection

4. NGFW and SASE Solution Maintenance and Configuration (10%)
4.1 Hardware, VM-Series, CN-Series, and Cloud NGFW policy/profile/update/upgrade maintenance
4.2 Prisma Access policy/profile/update/upgrade/monitoring/logging maintenance

5. Infrastructure Management and CDSS (17%)
5.1 CDSS security policies, profiles, and updates
5.2 IoT Security policies, Device-ID, monitoring, and logging
5.3 Enterprise DLP/SaaS Security encryption, access, monitoring, and logging
5.4 Supported products, device onboarding, reporting, and configuration management in SCM/Panorama

6. Connectivity and Security (13%)
6.1 Segmentation, policies, logging/monitoring, and certificates across on-premises, cloud, and hybrid networks
6.2 Remote-access components, segmentation, security-policy tuning, monitoring/logging, and certificates
