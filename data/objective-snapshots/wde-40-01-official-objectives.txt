Normalized, paraphrased objective snapshot

Block 1: HTML Fundamentals — 6 items, 15%
1.1 Build a standards-mode HTML document with doctype, language, head metadata, title, and body.
1.2 Distinguish the default behavior and appropriate use of block and inline elements.
1.3 Encode reserved characters with entities and use non-breaking spaces only where meaningful.
1.4 Declare UTF-8 and keep document, editor, and server encodings consistent.
1.5 Write useful HTML comments without exposing private information.
1.6 Apply html, head, title, and body correctly and validate the resulting skeleton.

Block 2: Text Formatting and Structure — 8 items, 20%
2.1 Use strong, em, u, del, sup, sub, and mark according to meaning rather than appearance.
2.2 Build a logical heading hierarchy that supports navigation and accessibility.
2.3 Structure prose with paragraphs and control visual spacing with CSS.
2.4 Use br for meaningful line breaks and hr for thematic changes.
2.5 Mark block and inline quotations, works, and abbreviations with appropriate elements.
2.6 Mark code, preserved text, user input, and program output with code, pre, kbd, and samp.
2.7 Choose and nest ordered, unordered, and description lists correctly.
2.8 Construct data tables with captions, row groups, header cells, scope, and sparing cell spans.

Block 3: Multimedia and Hyperlinks — 8 items, 20%
3.1 Embed responsive images with appropriate alternative text, intrinsic size, srcset, and sizes.
3.2 Create descriptive internal, external, fragment, email, telephone, and download links; secure new-window links.
3.3 Embed accessible audio and video with controls, sources, captions, posters, and appropriate playback behavior.
3.4 Create image maps while preserving keyboard access and equivalent text alternatives.
3.5 Associate self-contained media and captions with figure and figcaption.
3.6 Embed external content with titled, responsive iframes and appropriate sandbox/referrer controls.
3.7 Turn media into links while preserving destination meaning, focus visibility, and target size.
3.8 Declare and test favicons in suitable formats and sizes.

Block 4: Forms and Styling — 10 items, 25%
4.1 Choose suitable form controls and input types; connect labels and stable names/IDs.
4.2 Select GET for safe retrieval and POST for state changes; configure action, encoding, and autocomplete.
4.3 Group related inputs with fieldset and legend; distinguish value, placeholder, disabled, and readonly.
4.4 Apply native constraints such as required, min/max, maxlength, pattern, and step and provide useful errors.
4.5 Build labelled select controls and group options when needed.
4.6 Apply inline and internal CSS while recognizing that external stylesheets normally scale better.
4.7 Use classes for reusable styling and IDs for unique identifiers/anchors rather than high-specificity styling.
4.8 Establish readable color and typography with adequate contrast.
4.9 Use span and div only when a more meaningful semantic element does not fit.
4.10 Reason about content, padding, border, margin, and border-box sizing.

Block 5: Accessibility, Best Practices, and Modern HTML — 8 items, 20%
5.1 Apply the perceivable, operable, understandable, and robust accessibility principles.
5.2 Use native semantics first and add accurate ARIA roles, states, and properties only when needed.
5.3 Structure landmarks with header, nav, main, article, section, aside, and footer.
5.4 Annotate structured data with microdata/Schema.org and recognize microformat use cases.
5.5 Use Geolocation with permission/error handling and Web Storage with privacy/quota awareness.
5.6 Embed accessible, scalable SVG and reuse symbols where appropriate.
5.7 Produce readable, minimal, semantic markup and reduce avoidable loading cost.
5.8 Combine automated checks with keyboard and screen-reader spot checks.

Passing requirement: cumulative normalized score of at least 75%.
