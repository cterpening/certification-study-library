Exam Objectives by Block
Block 1 – Basic Concepts
(Exam items: 4 | Weight: 13.25%)
1.1 Explain the purpose of compilation and describe the role of the compiler and IDE.
1.2 Distinguish between language elements, lexis, syntax, semantics, and portability.
1.3 Identify valid literals: characters, numbers, strings, and scientific notation.
1.4 Use printf() and puts() functions for output; describe the role of the main() and return.
1.5 Understand numeral systems (binary, octal, decimal, hexadecimal).
1.6 Apply basic arithmetic operators and declare variables.
Block 2 – Data Types, Evaluations, and Basic I/O Operations
(Exam items: 4 | Weight: 13.25%)
2.1 Differentiate between primary and derived data types and use type modifiers.
2.2 Perform type casting and conversions.
2.3 Declare variables, assign values, and define constants.
2.4 Use scanf(), puts(), and printf() for input/output and format output using specifiers.
2.5 Recognize header files and perform basic calculations.
Block 3 – Arithmetic, Logical, and Bitwise Operators
(Exam items: 4 | Weight: 13.25%)
3.1 Use unary and binary operators, respecting operator precedence and associativity.
3.2 Perform arithmetic calculations and rounding operations.
3.3 Use increment/decrement and compound assignment operators.
3.4 Apply bitwise shifts (>>, <<) and logical operators (AND, OR, NOT).
3.5 Construct and interpret truth tables.
Block 4 – Flow Control: Decision-Making Statements
(Exam items: 4 | Weight: 13.25%)
4.1 Apply conditional statements: if, if-else, if-else if, if-else if-else.
4.2 Use multiple and nested conditions.
4.3 Implement switch, case, and default statements.
4.4 Understand control instructions.
Block 5 – Flow Control: Loops
(Exam items: 5 | Weight: 16.50%)
5.1 Use loop constructs: while, for, and do...while.
5.2 Iterate through sequences and recognize infinite loops.
5.3 Understand loop structure, nesting, and execution.
5.4 Control loops using break and continue.
Block 6 – Arrays, Pointers, and Memory Management
(Exam items: 5 | Weight: 16.50%)
6.1 Create and manipulate single- and multidimensional arrays.
6.2 Use initiators and sort array data.
6.3 Declare and manipulate pointers, including NULL, arithmetic, and references.
6.4 Distinguish between pointers and arrays.
6.5 Perform memory allocation with malloc() and deallocation with free().
Block 7 – String Manipulation
(Exam items: 2 | Weight: 7%)
7.1 Use character arrays and ASCII codes.
7.2 Initialize and process strings.
7.3 Apply string functions: strcpy, strlen, strcat.
7.4 Use string header files.
Block 8 – The Basics of Functions
(Exam items: 2 | Weight: 7%)
8.1 Define, declare, and invoke functions.
8.2 Use parameters and return values.
8.3 Recognize and apply selected C standard library functions.
