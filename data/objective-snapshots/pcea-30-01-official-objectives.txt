Block 1: Fundamentals of Automation — 6 items, 13%
1.1 Routine/repetitive candidates. 1.2 Benefits/limits. 1.3 scripting vs process automation vs orchestration. 1.4 basic ROI. 1.5 why Python.

Block 2: Basic Command-Line Automation with Python — 9 items, 19.5%
2.1 Running scripts, sys.argv and virtual environments. 2.2 shebang, output/error redirection and environment variables. 2.3 OS-tool integration, subprocess and use cases.

Block 3: Logging and Monitoring Essentials — 7 items, 15%
3.1 Logging purpose/configuration. 3.2 levels, formatting and file-operation logging. 3.3 monitoring strategies and log-based debugging.

Block 4: Basic File and Data Automation — 8 items, 17.5%
4.1 pathlib/os file/folder operations, shutil and errors. 4.2 CSV versus JSON and their modules. 4.3 safe/reliable file handling and ethical/security/privacy considerations.

Block 5: Basic Web and API Automation — 8 items, 17.5%
5.1 Scraping vs APIs and ethics/legal constraints. 5.2 requests.get and JSON responses. 5.3 BeautifulSoup HTML extraction and logging. 5.4 REST and simple API interpretation.

Block 6: Scheduling, Notifications, and Reporting — 8 items, 17.5%
6.1 Scheduling and schedule library. 6.2 cron versus Windows Task Scheduler. 6.3 smtplib and desktop notifications. 6.4 text/HTML reports and logging.
