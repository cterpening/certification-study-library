Credential: required prerequisites plus Core Practical and one Elective Practical within one year.

CORE PRACTICAL
1. Infrastructure (27%)
1.1 Availability: LACP, FGCP, FGSP, FortiAnalyzer/FortiAuthenticator/FortiManager HA, virtual clustering, VRRP
1.2 Architecture: application performance, multi-data-center, redundant connectivity, work from anywhere
1.3 Optimization: hardening and performance tuning
1.4 Management: VM bootstrap, firmware, FortiAnalyzer, FortiGuard, policy packages, logs, multi-tenancy, VDOMs, operation modes, VM deployments, workspace mode

2. Networking (40%)
2.1 SASE: SPA preparation, SD-WAN on-ramp and SPA
2.2 Routing/VPN/SD-WAN: asymmetric routing, BFD, dynamic/static/policy/SD-WAN routing, ECMP, multicast, VRF, ADVPN, dial-up/IPsec/overlay VPN, PQC key exchange, SSL VPN, VXLAN over IPsec, ZTNA
2.3 NGFW: Fabric integrations, inspection/policy/proxy/transparent modes, IPv6, security profiles, DLP, web filtering, SSL inspection and IPS
2.4 Networking: explicit/transparent proxy, inter-VDOM, local-in/local-out, NAT, shaping, VLANs, zones and related routing

3. Authentication (14%)
3.1 Solutions: 802.1X, administrator/API/device/user authentication, captive portal, Fabric/Fortinet/RADIUS/Syslog SSO, IAM, LDAP, OAuth, RADIUS, SAML, SNMPv3, SSOMA and TACACS+
3.2 Management: CA, certificate authentication, CMP, OCSP, PKI and SCEP

4. Fortinet Security Fabric (19%)
4.1 Automation/integration: parameters, stitches, scripts, APIs, meta fields, Fabric integration/objects and threat feeds
4.2 Logging/analytics: custom FortiAnalyzer views, device logging, event handlers, FortiView, incidents/events, log management, triage, operation modes and reporting

SECURE NETWORKING ELECTIVE
5. Secure SD-WAN (25%)
5.1 Advanced overlay/VPN/routing, ADVPN 2.0/legacy, app routing, BGP multipath/dynamic BGP, FEC, QoS/MOS/SLA, health signaling, SD-Branch, hubs/full mesh and VRF
5.2 Orchestration: Central VPN, Overlay Orchestrator, templates/variables, Jinja and ZTP
6. Endpoint Security (20%)
6.1 ZTNA profiles, agentless portal, tags, HTTP/HTTPS and TCP proxy
6.2 Endpoint malware/anti-exploit/antiransomware, FortiClient/EMS HA/integration, quarantine and sandbox integration
7. Threat Mitigation (30%)
7.1 Custom IPS, DDoS, deep inspection, FortiGuard, sandbox inline/sniffer/HA, threat feeds and vulnerability scan
7.2 NGFW: CASB, CGNAT, domain fronting, Fabric, IPv6, OT, policy/proxy/inspection/transparent modes and profiles
8. Enterprise Networking (25%)
8.1 FortiSwitch/IoT/FortiLink, FortiNAC integration/HA/access controls
8.2 Advanced networking including EMAC VLAN, LAN extension, MAP-E, route leaking, QoS/shaping, VRF/VXLAN and VLAN inside VXLAN

APPLICATION SECURITY ELECTIVE
9. Email Security (27%)
9.1 Email infrastructure: archiving, DNS/domains, encryption/IBE, monitoring, quarantine, SMTP/IMAP/POP3, authentication and webmail
9.2 Antispam/threat: profiles, AV, bounce verification, CDR, DLP, reputation, IP/recipient/sender/session policies, sandbox, feeds and URL filtering
10. Application Delivery (44%)
10.1 Application access: Application Access Manager, SSO, Agentless Application Gateway, users/authentication
10.2 Load balancing: GLB/SLB/application load balancing, network security, scripting and WCCP
10.3 Web security: bot/API/DoS/IP/ML/OWASP/secure-connection/tracking/adaptive-learning/web-protection/vulnerability-scanning capabilities
11. Threat Detection (12%)
11.1 Sandbox analysis/detection: air-gapped, behavior, on-demand, risk, jobs/policies, website/network share/OT, dedicated internet and inline
12. Infrastructure (17%)
12.1 FortiADC/FortiWeb/FortiMail/FortiSandbox clustering, VDOM/ADOM, logging/reporting, operation modes, MTA/BCC, Kubernetes ingress and Fabric

SECURITY OPERATIONS ELECTIVE
13. Automation (23%)
13.1 FortiManager Jinja/provisioning and Fortinet APIs
13.2 Automated response, connectors, FortiAnalyzer/FortiSOAR playbooks, Fabric, outbreak alerts, workflows/workspaces and FortiSIEM automation
14. Analytics and Reporting (26%)
14.1 CMDB, compliance, parsers, datasets, reports, analytics, hcache, SQL, monitors and dashboards
14.2 Case management, EDR incidents, IoCs, Investigation View, searches/filters and SIEM analytics search
15. Threat Handling (29%)
15.1 EDR hunting/XDR, device isolation/remediation and FortiEDR Connect
15.2 IR, war rooms, simulation and incident frameworks
15.3 Application/device/execution/exfiltration/ransomware prevention, suspicious-indicator blocking and vulnerability management
16. Infrastructure (22%)
16.1 Health, CMDB, collectors, device support, HTTP poller, tenancy, RBAC, security management and segmentation
16.2 FortiEDR/FortiAnalyzer/FortiManager/FortiSOAR/FortiSIEM HA
16.3 FortiSOAR Application Editor, Content Hub, modules, policy analysis, workforce management, reports/dashboards, solution packs and widgets
