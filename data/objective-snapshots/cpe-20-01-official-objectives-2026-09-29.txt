Exam Objectives by Block
Block 1 – Syntax, Literals, and Operators
(Exam items: 9 | Weight: 28%)
1.1 Identify valid C++ syntax elements, keywords, and code structures.
1.2 Recognize C++ built-in data types and corresponding literals.
1.3 Describe the structure and declaration of the main() function and its parameters.
1.4 Apply arithmetic, relational, logical, bitwise, and assignment operators.
1.5 Determine operator precedence, associativity, and the impact on expressions.
1.6 Apply short-circuit logic in control expressions.
1.7 Use basic input/output streams (cin, cout, cerr) and manipulators (endl, setw).
Block 2 – Flow Control and Functions
(Exam items: 8 | Weight: 28%)
2.1 Describe and use conditional statements (if, else).
2.2 Use loop constructs (while, do, for) and loop control statements (break, continue).
2.3 Recognize the purpose of the goto statement and labeled statements.
2.4 Apply multiple-selection structures using switch, case, and default keywords.
2.5 Define, declare, and invoke functions with correct syntax.
2.6 Use return statements in typed and void functions.
2.7 Pass arguments by value, by reference, and by pointer.
2.8 Apply basic recursion to solve simple problems.
Block 3 – Vectors and Pointers
(Exam items: 7 | Weight: 24%)
3.1 Declare, initialize, and manipulate vectors and arrays, including multidimensional arrays.
3.2 Access vector data using the data() method.
3.3 Declare and initialize pointers, including the use of nullptr.
3.4 Dereference pointers and use the address-of operator (&).
3.5 Perform pointer conversions using static_cast and dynamic_cast.
3.6 Manage dynamic memory with new, delete, and delete[].
Block 4 – Structures and Strings
(Exam items: 6 | Weight: 20%)
4.1 Declare and define structures.
4.2 Access structure members using the dot (.) operator.
4.3 Declare vectors of structures and access their fields.
4.4 Declare, initialize, and manipulate std::string objects.
4.5 Perform basic string operations and comparisons.
