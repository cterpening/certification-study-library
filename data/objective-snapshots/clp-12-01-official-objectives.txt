CLP-12-01 objective snapshot
Source: https://cppinstitute.org/clp
Verified: 2026-09-02

Block 1 - Applied Evolution of C Programming (8 items; 14.5%)
1.1 ANSI C, C89, C99, and C11 history and significance
1.2 Obsolete versus modern constructs
1.3 Trigraphs, digraphs, and changing function declarations
1.4 C11 keywords including _Alignof and _Generic

Block 2 - Variadic Functions and Macros (5 items; 9%)
2.1 Calling conventions, stack behavior, and variadic parameters
2.2 stdarg.h macros including va_start() and va_end()
2.3 Variadic I/O including vprintf() and vsprintf()

Block 3 - Fundamentals of Low-Level I/O (7 items; 13%)
3.1 POSIX, API, ABI, and WINAPI distinctions
3.2 File system calls including open(), read(), and close()
3.3 File-descriptor controls including fcntl() and ioctl()

Block 4 - Memory and String Handling (9 items; 16%)
4.1 Standard string and memory functions
4.2 qsort() and bsearch()
4.3 Selecting memory-allocation strategies
4.4 Wide characters, Unicode, and internationalization

Block 5 - Process and Thread Management (5 items; 9%)
5.1 Process/thread history and roles
5.2 Unix and Windows models
5.3 Thread safety and environmental effects
5.4 The C11 threading model

Block 6 - Numerical Types and Computations (6 items; 11%)
6.1 IEEE 754, NaN, infinities, and signed zero
6.2 Floating-point behavior and precision hazards
6.3 External multiple-precision libraries

Block 7 - Network Socket Programming (7 items; 13%)
7.1 Socket and protocol fundamentals
7.2 Socket-based client/server communication
7.3 Endianness, message framing, and transmission order

Block 8 - Specialized Programming Considerations (8 items; 14.5%)
8.1 const versus volatile
8.2 goto and non-local jump risks
8.3 setjmp() and longjmp()
8.4 Undefined behavior and sequencing concerns
8.5 Function pointers, variable-length arrays, and complex declarations
