Normalized, paraphrased objective snapshot

1.0 Using Transforming Commands for Visualizations — 5%
1.1 Create categorical aggregations with chart.
1.2 Create time-series aggregations with timechart.

2.0 Filtering and Formatting Results — 10%
2.1 Create and transform fields with eval.
2.2 Filter results with search and where.
2.3 Replace null values with fillnull.

3.0 Correlating Events — 15%
3.1 Identify event groups that represent transactions.
3.2 Group transaction events by fields.
3.3 Group transaction events by fields and time constraints.
3.4 Retrieve and construct transactions in searches.
3.5 Report on transaction results.
3.6 Decide when transaction or stats is the better correlation approach.

4.0 Creating and Managing Fields — 10%
4.1 Use the Field Extractor to create regex-based fields.
4.2 Use the Field Extractor to create delimiter-based fields.

5.0 Creating Field Aliases and Calculated Fields — 10%
5.1 Explain, create, and use field aliases.
5.2 Explain, create, and use calculated fields.

6.0 Creating Tags and Event Types — 10%
6.1 Create and search tags.
6.2 Explain event types and appropriate uses.
6.3 Create an event type.

7.0 Creating and Using Macros — 10%
7.1 Explain search macros and their purpose.
7.2 Create and invoke a basic macro.
7.3 Define macro arguments and corresponding variables.
7.4 Invoke a macro with arguments.

8.0 Creating and Using Workflow Actions — 10%
8.1 Explain GET, POST, and Search workflow actions.
8.2 Create a GET workflow action.
8.3 Create a POST workflow action.
8.4 Create a Search workflow action.

9.0 Creating Data Models — 10%
9.1 Explain how data models support Pivot.
9.2 Identify data model attributes.
9.3 Create a data model.

10.0 Using the Common Information Model Add-On — 10%
10.1 Explain Splunk's Common Information Model.
10.2 Identify knowledge objects delivered with the CIM Add-on.
10.3 Normalize source data to CIM fields and tags.

The blueprint lists 65 questions and 60 total minutes, including 3 minutes for the exam agreement. It says related topics may appear and the guidelines can change without notice. It lists no prerequisite exams.
