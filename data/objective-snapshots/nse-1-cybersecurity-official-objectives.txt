Fortinet NSE 1 in Cybersecurity published-course snapshot
Source: https://training.fortinet.com/local/staticpage/view.php?page=nse_1
Course source: https://training.fortinet.com/local/staticpage/view.php?page=library_cybersecurity-and-cloud-fundamentals
Verified: 2026-09-02

Certification requirement
- Complete Cybersecurity and Cloud Fundamentals and pass the online exam presented at the end of the course.
- Fortinet states the awarded certification is active for 2 years from course completion.

Published course agenda (no weights published)
1. Intro to Cybersecurity
2. Threat Landscape
3. Social Engineering
4. Malware
5. Cryptography and the Public Key Infrastructure
6. Secure Networking
7. Authentication and Access Control
8. Endpoint Security
9. Secure Data and Applications
10. Cloud Security and Virtualization

Published course objectives
- Identify types of bad actors, their methods, and countermeasures.
- Explain how cryptography and effective endpoint security help secure a network.
- List ways to secure endpoints using authentication and host-hardening techniques.
- Explain how firewalls, web application firewalls, and network access control enhance cybersecurity.
- Describe differences in securing physical on-premises, virtual, and cloud networks and endpoints.

Boundary note
- Fortinet does not publish weighted domains, item count, time limit, or a standalone proctored-exam blueprint for this online course assessment.
