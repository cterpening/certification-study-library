Palo Alto Networks Certified Cloud Security Professional objective snapshot
Source: https://www.paloaltonetworks.com/content/dam/pan/en_US/assets/pdf/datasheets/education/cloudsec-professional-datasheet.pdf
Datasheet: August 2025
Verified: 2026-09-02

1. Security Operations Center Fundamentals (10%)
1.1 SOC roles/responsibilities, tools, technologies, and analytics
1.2 AI and machine learning in security operations
1.3 Threat intelligence in incident response/management
1.4 Incident categorization and prioritization

2. Cortex Fundamentals (15%)
2.1 Users, roles, IP/domain/URL indicators, logs, assets, compliance, rules, data protection, and use cases
2.2 Reports and dashboards
2.3 Data-source ingestion

3. Cloud Posture Security (29%)
3.1 CSPM, KSPM, AI-SPM, DSPM, agentless scanning, unified compliance, identity security, and vulnerability management
3.2 Posture Security Management Modules

4. Cloud Runtime Security (26%)
4.1 Cloud workload protection, cloud detection and response, web application/API security, and vulnerability management
4.2 Agent deployment and management

5. Application Security (20%)
5.1 ASPM, CI/CD posture, SCA, IaC security, secrets scanning, and scan management
5.2 Application-security use cases
