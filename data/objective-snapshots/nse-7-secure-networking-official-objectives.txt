Fortinet NSE 7 - Secure Networking 7.6 Architect objective snapshot
Source: https://training.fortinet.com/local/staticpage/view.php?page=secure_networking_architect_exam
Verified: 2026-09-02

1. System configuration and SD-WAN setup (20–30%)
1.1 Implement the Fortinet Security Fabric
1.1.1 Fabric connectors versus external connectors; Automation Stitches
1.1.2 SAML SSO, automated quarantine, IoC detection, FortiNAC dynamic addressing, FortiNDR integration, configuration backup and high-CPU automation use cases
1.2 Configure different operation modes for a high availability cluster
1.2.1 FGCP active-active, virtual clustering, virtual MAC, Ethernet/synchronization optimization and VDOM partitioning
1.2.2 FGSP standalone synchronization, coverage/limits, encrypted synchronization and asymmetric-inspection use cases
1.2.3 Effective HA using FGCP, FGSP and VRRP
1.3 Implement enterprise networks using VLANs and VDOMs
1.3.1 VLANs, virtual LAN switch, VDOM types, segmentation and inter-VDOM routing
1.4 Deploy an enterprise SD-WAN setup
1.4.1 Architecture/use cases, DIA topology/settings, members/zones, traffic distribution/health, widgets, logs and events

2. Central management (15–25%)
2.1 Implement branch configuration deployments
2.1.1 ZTP, device deployment, blueprints and CSV imports
2.2 Use SD-WAN Manager and overlay orchestration
2.2.1 FortiManager SD-WAN management, metadata variables, core settings, deployment planning and topology conversion
2.2.2 Templates/template groups, IPsec templates, hub-and-spoke, SD-WAN members and overlay templates

3. Security profiles (5–15%)
3.1 Manage SSL/SSH inspection profiles
3.1.1 Client versus protected-server inspection, certificate versus full inspection, SNI checks, false positives, code injection and certificate errors
3.2 Combine web filtering, application control, IPS and ISDB
3.2.1 Performance, client/server protection, false positives, code injection and CVE-pattern IPS sensors

4. Rules and routing (25–35%)
4.1 Implement OSPF
4.1.1 Access/prefix lists, route maps, redistribution, OSPF over IPsec and ECMP
4.2 Implement BGP
4.2.1 Filtering/route maps, redistribution, ECMP, loopback sources, neighbor groups, route reflectors, BFD and graceful restart
4.3 Design SD-WAN rules
4.3.1 Lookup/order, local-out/implicit rules, strategies, criteria, application learning/steering, ISDB criteria, preference and monitoring
4.4 Configure SD-WAN routing
4.4.1 Policy/route lookup, member/zone/probe routes, sessions/flags/reevaluation, SNAT routing changes and protocol-selection considerations

5. Advanced IPsec (25–35%)
5.1 Implement IPsec VPN IKEv2
5.1.1 Topology, DPD, NAT, certificates/OpenSSL, aggregates, overlapping routes, MTU/MSS/fragmentation, offload and FEC
5.1.2 FortiManager templates, metadata, single/dual hubs, VPN Manager and autorouting
5.2 Configure IPsec multihub, multiregion and large deployments
5.2.1 Dual hubs, BGP/self-healing, routing, multiregion, MSSP and VRF-aware overlays
5.3 Implement ADVPN
5.3.1 Shortcut negotiation, FortiManager, IPsec templates, SD-WAN, ADVPN 2.0 placeholders, timeout/failback/dependencies, BGP-on-loopback and route-reflection alternatives
