Block 1: Introduction to Data and Data Analysis Concepts — 9 items, 22.5%
1.1.1 Define data and explain how it becomes meaningful.
1.1.2 Classify data by type and format.
1.2.1 Identify data sources and collection methods.
1.2.2 Explain how data is stored and organized.
1.3.1 Describe the data lifecycle.
1.3.2 Discuss the value and challenges of lifecycle management.
1.4.1 Differentiate data analysis, data analytics, and data science.
1.4.2 Explain the data analytics workflow.
1.5.1 Describe ethical principles and legal frameworks.

Block 2: Python Basics for Data Analysis — 13 items, 32.5%
2.1.1 Variables, types and basic operations.
2.2.1 Lists; 2.2.2 tuples and sets; 2.2.3 dictionaries; 2.2.4 strings.
2.3.1 Functions; 2.3.2 scope; 2.3.3 try/except.
2.4.1 Boolean logic; 2.4.2 conditionals; 2.4.3 loops.
2.5.1 Standard modules/packages including csv; 2.5.2 external libraries and NumPy.

Block 3: Working with Data and Performing Simple Analyses — 13 items, 32.5%
3.1.1 Text files; 3.1.2 CSV.
3.2.1 Missing/invalid data; 3.2.2 duplicates/normalization; 3.2.3 string cleaning; 3.2.4 conversions, formatting and dates.
3.3.1 Built-in aggregation; 3.3.2 statistics/math/Counter; 3.3.3 NumPy operations; 3.3.4 conditional metrics.
3.4.1 Sorting/filtering; 3.4.2 unique values/frequencies; 3.4.3 correlation and outliers.

Block 4: Communicating Insights and Reporting — 5 items, 12.5%
4.1.1 Visualization types and uses; 4.1.2 interpretation and misleading visuals.
4.2.1 Data storytelling; 4.3.1 analytical reports; 4.4.1 presentations.
