Section 1: Advanced Object-Oriented Programming — 15 items, 35%
1.1 OOP terminology, classes, methods, variables, isinstance(), issubclass(), __init__().
1.2 Special methods for comparison, numeric/type conversion, representation, attribute and container access.
1.3 Inheritance, MRO, polymorphism, duck typing, composition, is-a/has-a.
1.4 *args, **kwargs, closures, function/class decorators, wrappers, stacking, __call__().
1.5 Class and static methods; cls; alternate constructors and class state.
1.6 Abstract classes and methods.
1.7 Attribute encapsulation and properties.
1.8 Subclass built-in classes.
1.9 Exception objects, chaining, __context__, __cause__, tracebacks.
1.10 Identity, shallow copy, deep copy.
1.11 Persistence with pickle and shelve.
1.12 Metaprogramming, type and metaclasses.

Section 2: Coding Conventions, Best Practices, and Standardization — 7 items, 12%
2.1 PEP 1, PEP 8, PEP 20, PEP 257 and Python philosophy.
2.2 PEP 8 layout, imports, whitespace, comments, naming, recommendations and checking tools.
2.3 PEP 257 docstrings, PEP 484 type hints, documentation tools, linters and fixers.

Section 3: GUI Programming — 8 items, 20%
3.1 GUI and event-driven concepts, widgets, events and toolkits.
3.2 tkinter Tk/mainloop, widgets, place/grid, callbacks, dialogs, validation, Canvas and bind().
3.3 Geometry, colors, event handling, widget properties and observable variables.

Section 4: Network Programming — 8 items, 18%
4.1 REST, sockets, domains, addresses, ports, protocols, clients and servers.
4.2 socket creation, connection, send/recv, close and error handling.
4.3 JSON and XML structures and Python processing.
4.4 requests, HTTP methods, CRUD, response analysis and status codes.

Section 5: File Processing and Environment — 7 items, 15%
5.1 sqlite3 connections, transactions, cursors and CRUD SQL.
5.2 XML building/parsing, CSV readers/writers, logging, handlers/formatters, ConfigParser and interpolation.
