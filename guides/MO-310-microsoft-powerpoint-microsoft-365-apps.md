## How to use this guide

Practice from audience and delivery requirements, not from decoration. Use layouts and theme controls for consistency, the Selection pane for object control, and Slide Show mode for final verification. Build a clean, accessible story inside the time limit.

> **About related items:** A `Related item:` callout provides useful communication or delivery context. It is supporting knowledge, not a claim that its wording is in the published objectives.

## 1. Presentations

Create and save in the required format; configure properties, slide size, orientation, themes, variants, and backgrounds. Use views appropriately: Normal for editing, Slide Sorter for sequence, Notes Page for notes, Slide Master for reusable structure, and Slide Show/Presenter View for delivery.

Add headers/footers, date/time, slide numbers, notes, and handout settings deliberately. Inspect compatibility, accessibility, metadata, hidden slides, comments, fonts, linked/embedded media, and print/export output. Rehearse timings only when the delivery contract needs them.

## 2. Slides

Create, duplicate, reuse, import, reorder, hide, and delete slides. Select the correct layout and reset a slide when placeholders drift from it. Organize sections for navigation and rearrangement. Apply a theme or layout consistently rather than formatting each slide independently.

Slide Master changes reusable layouts and placeholders; it should not be used as a hiding place for slide-specific content. Preserve source formatting only when intentional during reuse; otherwise align imported slides with the destination design.

> **Related item:** A layout is a contract for placeholder type and position. Manually drawn text boxes can look similar but do not inherit placeholder behavior as reliably.

## 3. Text, shapes, and images

Format text hierarchy, columns, spacing, bullets, numbering, links, and WordArt with restraint. Insert and edit shapes, connectors, icons, screenshots, and pictures. Crop, remove backgrounds, adjust, compress, recolor, rotate, align, distribute, group, layer, and size objects precisely. Use guides and the Selection pane rather than visual guessing.

Maintain aspect ratio when required. Understand placeholders versus independent objects and how grouping affects animation and editing. Add meaningful alt text and arrange reading order; do not communicate meaning by color alone.

## 4. Data, diagrams, and media

Use a table for precise values, a chart for patterns/comparisons, and SmartArt for relationships or process. Configure headers, styles, chart data, series, axes, legends, titles, and labels. Convert text to SmartArt only after confirming the hierarchy; convert back or use shapes when the design needs individual control.

Insert audio/video and configure trim, volume, start, loop, rewind, poster frame, captions, and playback options. Linked content can fail when files move; embedded content increases file size. Test on the actual delivery device. Use 3D models only when viewpoint or spatial understanding adds value.

## 5. Transitions and animations

Transitions act between slides; animations act on objects. Configure effect options, duration, sound, and advance settings. In the Animation pane, control order, trigger, Start On Click/With Previous/After Previous, delay, duration, repeats, and motion paths. Animate grouped versus individual objects intentionally.

Use motion to reveal sequence or focus attention. Too many effects reduce comprehension and increase failure risk. Preview the full show because editing-view indicators do not prove timing, media, links, or triggers.

## Integrated practice scenarios

1. **Quarterly review:** Create a branded deck with sections, charts, a comparison table, speaker notes, accessible objects, and a PDF handout.
2. **Training deck:** Build a process with SmartArt, screenshots, callouts, hyperlinks, progressive animation, captions, and an agenda/summary.
3. **Product pitch:** Reuse slides from two sources, normalize layouts, compress media, add a restrained transition scheme, and rehearse delivery.

## Hands-on labs

1. Create a theme-consistent ten-slide deck from an outline using suitable layouts.
2. Build and modify a Slide Master with title, content, comparison, and closing layouts.
3. Reuse slides from another deck and deliberately choose source or destination formatting.
4. Align, distribute, layer, group, crop, and add alt text to a complex object composition.
5. Represent one data set as a table and two chart types, then choose the clearest result.
6. Build a SmartArt process and convert/customize it where individual shape control is needed.
7. Insert and configure a captioned video plus audio; package and test the deck elsewhere.
8. Create an animation sequence with triggers, then run accessibility, inspection, export, and full-show checks.
